# Provenance

The studio is a design skill maintained in the [dsh-assistant](https://github.com/RegeneratusLabs/dsh-assistant) repository.

## Upstream

The studio is a fork of **huashu-design 3.3.0** by 花叔, released under the MIT license: https://github.com/alchaincyf/huashu-design

The design method, the reference documents and the assets originate upstream. Upstream works are credited here, not promoted.

## What this fork changed

- Translated the documentation to English.
- Renamed the plugin to `studio`.
- Moved the state directory to `~/.dsh-studio/`.
- Removed the upstream version check. This fork has no update check and never contacts upstream.
